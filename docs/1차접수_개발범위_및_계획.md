# 1차 접수 범위 및 향후 개발 계획

2026년 11월 15일 기준. 1차 PoC는 목업 차량 데이터와 실제 SDK·카카오 장소 검색을 활용해 핵심 흐름을 검증하고, 이후 약 2주간 실제 차량 간 연동으로 확장합니다.

## 1차 PoC 범위

| 기능 | 접수 목표 |
|---|---|
| **함께지도** | 차량 목록·상세에서 이동 정보 확인, 목적지·경유지 제안·수락 및 내비 반영 흐름 연결 |
| **차량 데이터 기반 제안** | 목업 에너지·운전 시간·ETA 간격 감지, 장소 추천·제안·응답 흐름 연결 |
| **음성 메시지** | STT 인라인 입력, 목업 텍스트 전달 및 수신 메시지 TTS 읽기 |
| **주차 조율** | 현장 제보·대체 주차장 제안 시나리오와 데이터 구조 검토 |

지도 표현·실시간 위치 공유와 실제 차량 간 통신은 후속 범위입니다. 추천 이동 시간은 직선거리 기반 추정값을 사용합니다.

## 구현 상태와 남은 연결 작업

접수 목표와 아래 구현 상태를 구분합니다.

| 구분 | 구현된 내용 | 남은 작업 |
|---|---|---|
| **이동 정보** | 가상 차량 이동·응답, 내 차 내비·EV 배터리 조회 | 실제 위치·차량 상태 공유 |
| **경로 조율** | 목적지 변경 감지·제안, 따라가기·같이 들르기, 경유지 추가·교체 및 실제 내비 요청 로직 | 버튼·확인 시트 연결, 자동 제안 카드 수락과 내비 반영 연결 |
| **장소 추천** | 카카오 검색·후보 순위 계산, 목업 상태 기반 자동 제안·카드 UI | 수동 추천 화면의 샘플 데이터를 실제 조회·제안 전송으로 교체 |
| **음성 메시지** | STT/TTS 엔진, 목업 저장소와 인라인 입력·전달 상태 UI 연결 | 사람 발화 정확도·오디오 동작 검증 |

## 후속 고도화

- **그룹 연동:** Firebase 방 생성·참여, 차량 상태·제안·응답·메시지 동기화 및 재접속 처리
- **실제 차량 데이터:** 위치·연료·주행 상태와 운전 시간 연동, 함께지도·실시간 위치 공유
- **추천 정확도:** NaviHelper 기반 도로 ETA, 우회 시간·시설 적합성·에너지 도달 가능성 평가
- **음성·주행 안정화:** 제안 음성 안내·응답, 오디오 포커스·선행 무음, 백그라운드 수신·주행 규제 대응 검증
- **주차 조율:** 공공 주차정보·현장 제보 연동, 대체 주차장 수락 후 경로 반영 및 최종 합류 안내

## 검증 기준

**1차 PoC:** 에뮬레이터와 앱 내부 가상 차량으로 제안·수락·거절·만료, 경유지 추가·교체, 내 차 내비 반영, 상태별 추천 및 STT/TTS 메시지 흐름을 확인합니다.

**후속 통합 검증:** 다중 차량의 상태 동기화, 개별 수락 후 내비 반영, 연결 복구·백그라운드 수신, 함께지도 및 주차 조율을 확인합니다.

기존 내비 경유지의 좌표가 없으면 경로 재전송 시 보존할 수 없는 한계가 있습니다. 시설 적합성·에너지 도달 가능성 및 실차 동작은 추가 검증이 필요합니다.
